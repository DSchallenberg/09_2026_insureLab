# pietkathon

Dieses Repository sammelt Materialien und vorkonfigurierte Übungsumgebungen.

## Struktur

```text
.
├── materials/
│   └── tipprunde_bundesliga_2026/
└── practice_playground/
```

## Hauptverzeichnisse

### `materials/`

Enthält eigenständige Beispiel- und Referenzmaterialien. Die Bundesliga-
Tipprunde ist eines dieser Beispiele und nicht der Schwerpunkt des
Repositories.

### `practice_playground/`

Enthält vorkonfigurierte Arbeitsumgebungen zum Ausprobieren und Üben.
